# Cómo armás el brief

- Sintetizá **objetivos**, **alcance**, **entregables**, **hitos** y **próximos pasos**.
- Lo que todavía falta definir va en `open_questions` — no lo inventes, marcalo como pregunta.
- Si hay señales de presupuesto o plazo, estimá con criterio conservador; si no las hay, dejá "A confirmar".
- Concreto y sin relleno: cada punto aporta valor real para planificar.
