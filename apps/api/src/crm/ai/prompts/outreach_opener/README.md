# outreach_opener

Drafts the first WhatsApp message for an approved prospect using owner voice and a real signal.

- **Purpose:** `AIPurpose.OUTREACH_OPENER`
- **Schema:** `crm.ai.schemas.outreach_opener.OutreachOpenerSchema`
- **Variables:** `business_name`, `services_offered`, `owner_voice`, `campaign_vertical`,
  `campaign_target_profile`, `prospect_profile`, `qualification_signals`, `recommended_angle`.
- **Runtime:** `generate_structured`, no tool-calling, no SafetyGuard.
